## 参与内容

我负责提出项目需求、规划功能，并在迭代过程中参与调试、问题定位和 API 使用探索。项目围绕文章发布、社区互动和内容辅助展开，涉及页面交互、后端业务、数据模型与模型接口之间的协作。

| 工作环节 | 我的参与 |
| --- | --- |
| 需求与功能规划 | 提出功能需求，围绕博客与社区使用场景规划功能 |
| 迭代调试 | 根据运行现象反馈问题，参与定位与调整 |
| API 使用 | 探索模型接口的配置与调用方式 |
| 项目理解 | 梳理视图、模型、表单与页面之间的关系，学习请求和数据处理流程 |
| 作品整理 | 整理项目说明、贡献范围、验证记录与演示证据 |

## 项目介绍

> 一个基于 Django、JavaScript 与 ORM 的博客社区项目，包含文章管理、用户互动和 AI 内容辅助。我参与需求与功能规划、迭代调试、问题定位及 API 使用探索。仓库提供源码、配置示例与验证记录，可展示页面、接口、后端与数据库之间的协作流程。
